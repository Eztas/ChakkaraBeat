## Project

chakkarabeat is a karaoke song management and recommendation app.

## Architecture

- Frontend: React + Vite
- Backend: Hono
- Runtime: Cloudflare Workers
- Database: Cloudflare D1
- ORM: Drizzle
- Linter + Formatter: Biome

## Verification

Run the following after changes:

- Linter + Formatter: pnpm check
